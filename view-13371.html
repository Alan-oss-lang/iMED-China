iMED中国分享会动态（十四讲）电子科大教授 段立新博士： Event Recognition in Personal Videos by Learning with Web Data: Domain Adaptation Approaches

2017-08-11iMED 中国

2017年8月11号，电子科大教授——段立新博士作为主讲教授，参与了我组的iMED中国分享会（十四讲），主讲题目是Event Recognition in Personal Videos by Learning with Web Data: Domain  Adaptation Approaches。

段立新博士作为刘江老师曾经的同事，电子科技大学教授、博导，国家信息中心和电子科技大学共建的大数据研究中心（北京）执行主任。曾于新加坡科技研究局和美国亚马逊公司西雅图总部任机器学习研究员。于2008年本科毕业于中国科技学技术大学，2012年博士毕业于新加坡南洋理工大学。主要研究方向为机器学习（迁移学习、深度学习等）、计算机视觉（图像分类、物体识别和检测等）、医疗影像分析（基于眼底图像的眼病辅助诊断等）。近年来在国际高水平会议和期刊发表论文30余篇，Google Scholar总引用次数超过1900次。2009年获得微软亚洲研究院授予大的微软学者奖，2010年获得CVPR最佳学生论文奖，2012年获得CVPR杰出审稿人奖。

会议中，段立新博士生动的向我们描述了他在利用网络弱分类的视频、图像来训练和增强个人视频的自动规整和索引自动建立的若干工作。演讲结束后段立新博士接受参会人员的提问，最后刘江老师对会议做了总结。

本次iMED中国分享会圆满成功，感谢各位的积极参与和段立新博士的精彩演讲。
